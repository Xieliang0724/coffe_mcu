# 咖啡台 LED 控制 · 蓝牙(BLE) 接口 v1.0

> **适用对象**：咖啡台智能终端
> **版本**：v1.0（2026-09-15）
> **用途**：App / 上位机通过 **蓝牙低功耗（BLE）** 连接终端，控制 10 路 LED；命令语义与 **TCP（9001）** 协议**完全一致**（复用同套 JSON 命令）。
> **说明**：本接口与 TCP(9001)、Modbus TCP(502) **可并存**，互不影响。

---

## 1. 连接与广播

| 项 | 值 |
|---|---|
| 广播名称 | **CoffeeTable-LED** |
| 广播类型 | BLE 低功耗广播（通用可发现） |
| 连接 | App 扫描到设备后建立 BLE 连接（无需配对约免，如需可加） |
| GATT 服务 UUID | `0000FFE0-0000-1000-8000-00805F9B34FB` |

---

## 2. 特征（Characteristics）

| 特征 | UUID | 权限 | 说明 |
|---|---|---|---|
| **CMD** | `0000FFE1-0000-1000-8000-00805F9B34FB` | Write / Write No Response | App 写入一条 JSON 命令（UTF-8） |
| **RESP** | `0000FFE2-0000-1000-8000-00805F9B34FB` | Read / **Notify** | 终端回传命令应答 JSON；App 需先**开启 Notify 订阅**才能收到 |
| **STA** | `0000FFE3-0000-1000-8000-00805F9B34FB` | Read | App 主动读取当前全部状态 JSON |

> **使用流程**：
> 1. App 连接终端 → 对 **RESP** 特征**订阅通知（Notify）**。
> 2. App 向 **CMD** 写入一条命令（单条 JSON，无需换行符）。
> 3. 终端执行后，通过 **RESP** Notify 回传应答 JSON。
> 4. 也可读 **STA** 直接获取当前全部状态。

---

## 3. 命令集（与 TCP 9001 完全一致）

支持命令：`ping`、`led_set`、`led_set_all`、`led_set_batch`、`led_status`。

**示例：点亮 CH3**
写 CMD（字节内容）：
```
{"cmd":"led_set","ch":3,"on":true}
```
终端 RESP Notify：
```
{"ok":true,"cmd":"led_set","data":{"ch":3,"on":true}}
```

**读全部状态**：写 `{"cmd":"led_status"}`，或直接读 STA 特征。

**其余命令语法 / 参数 / 错误码**，请参见《咖啡台 LED 控制 · TCP 自定义协议 v1.0.1》第 3、4、5 节（语义完全一致）：通道 `1..10`、`on` 仅布尔 `true/false`、批量原子、错误码 `INVALID_*` 等。

---

## 4. 说明

- **命令以单条 JSON 发送**（BLE 写入不按 `\n` 分帧，一次写入视为一条命令）。
- 应答通过 **Notify** 异步回传，App 按一次写入对应一次 Notify 处理即可。
- 与 TCP/Modbus 三套接口操作同一组通道：**并发写以最后到达者生效（last-write-wins）**，请避免同时操作。
- 终端**断电后所有 LED 恢复为灭**（无断电记忆），如需开机记忆请联系厂商定制。
